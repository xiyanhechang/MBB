MBB 是《杯杯倒满 Feed The Cups》地铁模式的选卡助手

## 【第一次使用】
双击「安装Interception.bat」，装完重启电脑

## 【日常使用】
1. 打开「MBB.exe」
2. 把卡名按顺序贴进队列框（→、逗号、空格、换行都能自动识别并分隔）
3. 让《杯杯倒满》处于地铁选卡界面，再点「开始」

## 【常见问题】
- 提示缺少 Interception：安装 Interception 后重启电脑
- 游戏请用窗口 / 无边框模式；独占全屏下无法截屏识别
- 如果因各种原因无法安装 Interception，程序会自动改用虚拟手柄：开始前先拔掉实体手柄，选完卡再插回
